What is a Web OS?

A Web OS is a web app that gives you a desktop-like workspace. You can open tools from a launcher and switch between them from one screen.

Where it runs

  1. Device OS. Windows, macOS or another operating system manages the device and its hardware.
  2. Browser. The browser runs the web app and controls which device features it can access.
  3. Web OS. The web app manages its own workspace, such as a launcher, windows and settings.

Example

Imagine opening a notes tool and a calculator side by side inside a browser tab. The Web OS arranges those two windows. Both tools are still running in the browser.

How does it relate to a PWA?

Web OS describes the workspace experience. PWA describes a way to deliver a web app, with features such as installation or offline access when implemented and supported. A Web OS can be delivered as a PWA and open in its own window.

什么是 Web OS？

Web OS 是一种提供桌面式工作区的网页应用。你可以从启动器打开工具，在同一个界面里切换使用。

它在哪里运行？

  1. 设备操作系统。 Windows、macOS 或其他操作系统负责管理设备及其硬件。
  2. 浏览器。 浏览器负责运行网页应用，并控制应用可以访问哪些设备功能。
  3. Web OS。 网页应用负责管理自己的工作区，例如启动器、窗口和设置。

举个例子

想象一下，你在同一个浏览器标签页里并排打开便签和计算器。Web OS 负责排列这两个窗口，两个工具都在浏览器中运行。

它和 PWA 有什么关系？

Web OS 描述的是工作区体验。PWA（渐进式网页应用） 描述的是一种网页应用交付方式。在应用实现且平台支持时，可以提供安装、离线访问等功能。Web OS 可以做成 PWA，安装后在独立窗口里打开。
